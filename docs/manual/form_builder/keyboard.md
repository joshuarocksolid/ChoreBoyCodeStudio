# Keyboard reference

Generated by `tools/form_builder_user_manual.py`. Do not edit by hand.

These are the form designer keys. Open `File > Settings... > Keybindings` and look under Form designer to change one.

Press Ctrl+R to go to a widget. Press Ctrl+Shift+R to open Preview. The Run behavior box on that toolbar runs the form's behavior. On a database form, that mode rolls the data changes back.

The full task pages start at [the form builder manual](index.md).
