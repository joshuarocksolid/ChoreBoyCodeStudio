# The canvas

The canvas is the page you design on. The chip at the top names the page and its layout, such as `invoice · Form layout`. The size beside it is the page width and height.

## Select a widget

Click a widget to select it. The click lands on the deepest widget under the pointer. Click a gap in a layout to select the layout.

Shift-click or Ctrl-click adds or removes one widget. Drag on empty space to draw a band around several widgets.

The chip under the selection shows the name. A sized widget adds Hug, Fill, or Fixed, as in `nameEdit · Hug × Fill`. Several widgets read `nameEdit + 2 more`.

Press Esc to select the parent. Press Tab and Shift+Tab to move to the next and previous widget.

Hover text names the widget. A field you can edit says `double-click to edit text`.

## Zoom

Use the toolbar buttons, or the percent menu. The menu lists `Fit`, `50%`, `75%`, `100%`, `150%`, and `200%`.

A new form opens at Fit. Fit stays at 100% or below, and it does not go below 75%.

`Ctrl+=` zooms in. `Ctrl+-` zooms out. `Ctrl+0` is 100%. `Ctrl+9` zooms to fit. The wheel zooms around the pointer.

## Design and XML

The toolbar has `Design` and `XML`. `XML` is also `Form > View XML` and `Ctrl+Shift+V`.

Edits in the XML view apply when you switch back to Design. The banner says `Edits here apply to the design when you switch back.` A file Code Studio cannot read stays on XML, and the banner shows the error.

## An empty form

An empty page says `Drop a widget here` and `or press / to search for one.` An empty box inside the page says `Drop widgets here`.

An empty tab widget says `No pages. Use + or Pages > Insert page.` An empty wizard says `No steps. Use + or Pages > Insert page.` An empty MDI area says `No windows. Use Pages > Add window.`
