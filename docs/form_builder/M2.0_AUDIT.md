# M2.0 audit: `_editor_widgets_by_path`

This is the §11.4 list. The dict still holds source editors. A text tab is in the dict. A Markdown tab is in the dict because the Markdown surface calls `create_source_editor`. A lazy sourced surface that never calls `create_source_editor` is absent from the dict. That surface is reached through `TabContentProviderRegistry.surface_for_path`.

Close, delete, move, and disk reload no longer require a widget.

## Lifecycle that used to walk the dict

`EditorTabLifecycleWorkflow.release_tab_content` unbinds the path, pops the widget when one exists, and calls `surface.release()`. A text tab has no surface, so the popped widget is `deleteLater`'d. Markdown releases the surface, which owns its source editor. A lazy surface releases the same way and the pop is a no-op.

`remove_tab_widget_for_path`, `handle_tab_close_requested`, and `reset_editor_tabs` call that release. Reset walks `EditorManager.open_paths()`, not the widget dict.

`ProjectTreeController.close_deleted_editor_paths` walks those same open tab paths and calls `release_tab_content`. A deleted lazy tab closes. It does not `continue` on a missing widget.

`ProjectTreeController.apply_path_move_updates` still moves a widget when one is present. It calls `rekey_tab_content` for every remapped path. Text tabs only move the widget and the draft key. Markdown with the same provider gets `file_path_changed` and `registry.rekey`. A rename whose new path has a different provider, or no provider, unbinds and releases the surface. A lazy surface follows that same provider check. The widget steps are skipped when the pop returns nothing.

`EditorSyncWorkflow.apply_disk_content` restores the surface when one is bound, and asks for an editor widget only when there is no surface. Text tabs still `setPlainText`. Markdown and a lazy surface both get `restore_text(..., "external_reload")` and `mark_saved(saved_text=text)`.

`ExternalFileChangeWorkflow.check_and_handle` asks its host for both `editor_widget_for_path` and `surface_for_path`. It returns `SKIPPED` only when there is no tab, or when there is neither a widget nor a surface. A clean tab, sourced or not, still uses the reload confirmation. A dirty text or Markdown buffer uses the v0.4.13 disk-changed dialog (`present_disk_changed`: keep my version, reload, compare), not the generic unsaved-changes dialog. A dirty lazy tab with a content source and no source editor still uses the three-way unsaved-changes prompt (`DocumentScope.EXTERNAL_RELOAD`). Reload goes through `apply_disk_content`, so the surface gets `restore_text(..., "external_reload")`. When the buffer already matches disk, the tab is marked saved with `saved_text` set to the disk text, so a sourced tab does not serialize again.
