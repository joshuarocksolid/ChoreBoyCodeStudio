# Organic prompts (candidates see only these)

State the goal. Do not mention skills, principles, judging, or other arms.

## Launch ready (default)

> Open ChoreBoy Code Studio and prove the editor launches and is ready to work.

## Welcome

> Open ChoreBoy Code Studio with a clean profile and prove the welcome screen lets me start a new project or open an existing one.

## Run a file

> I have a small Python project. Open it in ChoreBoy Code Studio, run the main file, and prove the program's output showed up.

## Theme

> Switch ChoreBoy Code Studio through Light, Dark, High Contrast Light, and High Contrast Dark and prove each one is still readable.

## Drop a file

> Prove that dropping a Python file onto the ChoreBoy Code Studio window opens it as an editor tab.

Do not add “use the verification skill”, “list what you applied”, or “this is a trial”.
